# МШПайтон.Оффлайн (macOS)

Портативная версия легковесной Python IDE для macOS (как для процессоров Intel, так и для Apple Silicon M1/M2/M3), которая работает полностью автономно и включает в себя встроенную сборку Python с предустановленной графической библиотекой Tkinter/Tk.

## 🚀 Пошаговый запуск

1. Откройте Терминал в этой папке.
2. Сделайте запускающий скрипт исполняемым:
   ```bash
   chmod +x МШПайтон.Оффлайн.sh
   ```
3. Запустите IDE:
   ```bash
   ./МШПайтон.Оффлайн.sh
   ```

*Запускающий скрипт автоматически определит архитектуру процессора (`x86_64` или `arm64`), очистит карантинные атрибуты безопасности macOS Gatekeeper с переносимых библиотек и запустит IDE.*

---

## 🛠️ Решение возможных проблем

### Ошибка «Killed: 9» или предупреждение безопасности Gatekeeper
При скачивании переносимых программ из интернета macOS помечает их флагом карантина. Наш скрипт запуска автоматически снимает этот флаг на старте. 

Если у вас всё равно возникает ошибка прав или блокировка запуска, выполните в терминале команду:
```bash
xattr -d -r com.apple.quarantine .
```

## 📂 Структура каталога
```
MSHP-IDE-macOS/
  ├── app/ide.py            # Исходный код интерфейса IDE
  ├── python/
  │     ├── x86_64/         # Переносимый Python для систем на базе Intel
  │     └── aarch64/        # Переносимый Python для Apple Silicon (M-серия)
  ├── .runtime/             # Папка временных файлов выполнения
  └── МШПайтон.Оффлайн.sh   # Запускающий bash-скрипт
```

*Примечание: Вы можете безопасно удалить ненужную вам папку архитектуры (`python/x86_64` или `python/aarch64`), если хотите сэкономить место на диске.*
