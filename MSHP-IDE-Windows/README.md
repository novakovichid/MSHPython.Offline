# МШПайтон.Оффлайн (Windows)

Портативная версия легковесной Python IDE для Windows (x86_64), которая работает полностью оффлайн и включает в себя встроенную сборку Python с предустановленной графической библиотекой Tkinter/Tk.

## 🚀 Пошаговый запуск

1. Перейдите в эту папку.
2. Дважды кликните по файлу `МШПайтон.Оффлайн.bat` (или запустите его через командную строку / PowerShell).

*IDE автоматически инициализирует переносимый интерпретатор Python и запустит среду разработки.*

---

## 📂 Структура каталога
```
MSHP-IDE-Windows/
  ├── app/ide.py            # Исходный код интерфейса IDE
  ├── python/               # Встроенный переносимый Python для Windows
  ├── .runtime/             # Папка временных файлов выполнения
  └── МШПайтон.Оффлайн.bat  # Запускающий bat-скрипт
```
