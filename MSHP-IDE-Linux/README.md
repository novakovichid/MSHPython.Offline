# МШПайтон.Оффлайн (Linux)

Портативная версия легковесной Python IDE для Linux (x86_64 и ARM/AArch64), которая работает полностью оффлайн и включает в себя встроенную сборку Python с предустановленной графической библиотекой Tkinter/Tk.

## 🚀 Пошаговый запуск

1. Откройте терминал и перейдите в эту папку:
   ```bash
   cd MSHP-IDE-Linux
   ```
2. Сделайте запускающий скрипт исполняемым:
   ```bash
   chmod +x МШПайтон.Оффлайн.sh
   ```
3. Запустите IDE:
   ```bash
   ./МШПайтон.Оффлайн.sh
   ```

*Запускающий скрипт автоматически определит архитектуру вашей системы (`x86_64` или `aarch64`), применит нужные переменные окружения и запустит IDE.*
---

## 📂 Структура каталога
```
MSHP-IDE-Linux/
  ├── app/ide.py            # Исходный код интерфейса IDE
  ├── python/
  │     ├── x86_64/         # Переносимый Python для Intel/AMD систем
  │     └── aarch64/        # Переносимый Python для ARM систем
  ├── .runtime/             # Папка временных файлов выполнения
  └── МШПайтон.Оффлайн.sh   # Запускающий bash-скрипт
```

*Примечание: Вы можете безопасно удалить ненужную вам папку архитектуры (`python/x86_64` или `python/aarch64`), если хотите сэкономить место на диске.*
