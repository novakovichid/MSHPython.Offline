# МШПайтон.Оффлайн (Portable Python IDE)

Полностью автономная, быстрая и легковесная среда разработки Python (IDE) со встроенным интерпретатором и поддержкой графики (включая модуль `turtle`), работающая без подключения к интернету и сторонних установщиков.

Проект разделён по операционным системам. Внутри каждого каталога находится своя портативная (portable) версия Python и преднастроенный скрипт для мгновенного запуска.

## 📁 Структура проекта
```
МШПайтон.Оффлайн/
  ├── MSHP-IDE-Windows/    # Версия для Windows (x86_64)
  ├── MSHP-IDE-macOS/      # Версия для macOS (Intel & Apple Silicon)
  └── MSHP-IDE-Linux/      # Версия для Linux (x86_64 & AArch64)
```

---

### 💻 Windows
1. Перейдите в каталог `MSHP-IDE-Windows/`.
2. Дважды кликните по файлу `МШПайтон.Оффлайн.bat`.
*IDE запустится автоматически, используя встроенный переносимый Python.*

---

### 🍎 macOS
1. Откройте терминал в папке `MSHP-IDE-macOS/`.
2. Разрешите исполнение запускающего скрипта:
   ```bash
   chmod +x МШПайтон.Оффлайн.sh
   ```
3. Запустите скрипт:
   ```bash
   ./МШПайтон.Оффлайн.sh
   ```
*Скрипт автоматически определит архитектуру процессора (Intel или Apple Silicon), снимет карантин безопасности macOS Gatekeeper с переносимых бинарных файлов и запустит IDE.*

---

### 🐧 Linux
1. Откройте терминал в папке `MSHP-IDE-Linux/`.
2. Разрешите исполнение запускающего скрипта:
   ```bash
   chmod +x МШПайтон.Оффлайн.sh
   ```
3. Запустите скрипт:
   ```bash
   ./МШПайтон.Оффлайн.sh
   ```
*Скрипт автоматически выберет архитектуру (x86_64 или AArch64) и запустит программу.*

> [!TIP]
> **Отображение шрифтов в Linux / WSL:**
> Если при запуске на чистой Linux или WSL интерфейс отображается в виде кодов (`\u0424\u0430\u0439\u043b` вместо «Файл»), это значит, что в системе отсутствуют библиотеки рендеринга шрифтов Xft. Просто выполните в терминале:
> `sudo apt update && sudo apt install -y libxft2 libxss1`
> Скрипт при следующем запуске сам переключится на современные сглаженные русские шрифты.

---

## ✨ Возможности IDE
* **Полная автономность:** Работает без интернета, не требует предустановленного Python.
* **Вкладки редактора:** Одновременная работа с несколькими файлами.
* **Интегрированная Черепашка:** Модуль `turtle` рисует прямо во встроенной панели справа (без открытия лишних окон), а `input()` работает через интерактивное поле ввода IDE.
* **Пошаговый отладчик:** Построчный запуск кода с наглядным выделением текущей строки.
* **Тёмная тема:** Переключение оформления интерфейса в один клик.
* **Быстрый шеринг:** Экспорт и импорт кода проекта через короткие текстовые хэши.
