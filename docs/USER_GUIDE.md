# Руководство пользователя МШПайтон.Оффлайн

Подробное руководство по установке, запуску и работе в автономной среде разработки МШПайтон.Оффлайн.

---

## 🚀 Быстрый старт

### 💻 Windows
1. Перейдите в каталог `MSHP-IDE-Windows/`.
2. Дважды кликните по файлу `МШПайтон.Оффлайн.bat` (или запустите его через командную строку / PowerShell).

---

### 🍎 macOS
1. Откройте Терминал и перейдите в каталог проекта:
   ```bash
   cd MSHP-IDE-macOS
   ```
2. Разрешите исполнение запускающего скрипта:
   ```bash
   chmod +x МШПайтон.Оффлайн.sh
   ```
3. Запустите скрипт:
   ```bash
   ./МШПайтон.Оффлайн.sh
   ```

---

### 🐧 Linux
1. Откройте терминал и перейдите в каталог проекта:
   ```bash
   cd MSHP-IDE-Linux
   ```
2. Разрешите исполнение запускающего скрипта:
   ```bash
   chmod +x МШПайтон.Оффлайн.sh
   ```
3. Запустите скрипт:
   ```bash
   ./МШПайтон.Оффлайн.sh
   ```

## 🖥️ Описание интерфейса
* **Вкладки редактора** — позволяют работать с несколькими файлами (модулями) одновременно.
* **Панель запуска** — содержит зелёную кнопку «Запустить main.py» (F5) для запуска программы, кнопку пошагового выполнения и красную кнопку «Остановить» (Shift+F5). Кнопка остановки неактивна, когда программа не запущена.
* **Поле ввода** — интерактивное текстовое поле между окном редактора и консолью для передачи данных в `input()`.
* **Консоль** — отображает вывод программы, сообщения об ошибках и служебные статусы выполнения.
* **Тёмная тема** — переключатель оформления интерфейса в правом верхнем углу.
* **Встроенная панель Черепашки (Turtle)** — автоматически появляется в правой части окна, если в коде присутствует инструкция `import turtle`.
* **Меню «Полезное»** — содержит полезные инструменты форматирования (например, «Сделать отступ»).

---

## ⚙️ Настройки приложения
Окно настроек открывается через главное меню **«⚙ Настройки»**:
* Переключение цветового оформления (светлая/тёмная темы).
* Выбор режима сохранения файлов перед запуском:
  * *Спрашивать* перед запуском.
  * *Всегда* сохранять автоматически.
  * *Никогда* не сохранять (запуск во временной директории).

---

## 📁 Работа с файлами проекта
* Все основные операции с файлами («Новый», «Открыть», «Сохранить», «Сохранить все», «Закрыть») вынесены на верхнюю панель инструментов.
* При выходе из приложения или закрытии вкладки IDE обязательно спросит подтверждение, если в файле есть несохранённые изменения.
* Первая вкладка в новом проекте автоматически называется `main.py`. Все последующие — `module1.py`, `module2.py` и т.д.
* При создании нового модуля IDE подбирает **минимальный свободный номер** (если удалить `module1`, новый файл снова получит это имя).
* Если вкладка `main.py` пуста, то кнопка «Открыть» загрузит выбранный файл прямо в неё.

## ✍️ Редактирование и форматирование кода
* **Клавиша Tab** — автоматически сдвигает все выделенные строки вправо.
* **Меню Полезное ➔ Сделать отступ** — вручную добавляет стандартный отступ слева к выделенным строкам.

---

## ⚡ Запуск импортов без сохранения вкладок
* При запуске проекта с несохранёнными вкладками IDE автоматически собирает их во временную изолированную директорию внутри `.runtime/`.
* Благодаря этому конструкции `import module1`, `import module2` и перекрестные импорты между вкладками работают мгновенно, без необходимости предварительно сохранять все файлы на жесткий диск.

---

## ⌨️ Управление вводом и выводом (stdin/stdout)
* Запуск программы выполняется по клавише **F5** или по кнопке «Запустить main.py».
* Передача данных в программу:
  * **Enter** — отправить текст из поля ввода в программу.
  * **Ctrl+Enter** — перенос строки в поле ввода (для ввода многострочных данных).
* Любой ввод пользователя отображается в консоли с префиксом `>`.
* Когда запущенный процесс ожидает ввод (`input()`), поле ввода автоматически фокусируется и подсвечивается синим цветом.

---

## 🐢 Особенности встроенного режима Turtle (Черепашка)
* Если в коде есть `import turtle`, графический холст открывается **внутри главного окна IDE справа** (внешнее окно не появляется).
* **Размер холста зафиксирован на 400 × 400 пикселей** и не искажается при изменении размеров главного окна.
* Центр холста находится в точке `(0, 0)`, диапазон координат — от `-200` до `200` по обеим осям.
* Интерактивный метод `input()` перенаправлен в графическое поле ввода IDE.
* После завершения выполнения рисунок черепашки остается на экране и не закрывается.
* Функции блокировки экрана (например, `screen.mainloop()`) игнорируются, сохраняя отзывчивость интерфейса IDE.

## 📦 Комплектация и добавление библиотек
* В дистрибутив уже встроен **полный стандартный Python** (stdlib) и графическая библиотека **Tkinter/Tk**.
* Сторонних внешних библиотек в комплекте нет ради уменьшения веса архива.
* **Как установить свои библиотеки:**
  1. **Windows:** скопируйте необходимые библиотеки в каталог `python/Lib/site-packages`.
  2. **macOS / Linux:** скопируйте библиотеки в каталог `python/<архитектура>/lib/python3.13/site-packages`.

---

## 💾 Экономия дискового пространства
На macOS и Linux поставляются сборки для двух разных архитектур процессоров. Чтобы сэкономить место на диске, вы можете безопасно удалить неиспользуемую папку внутри каталога `python/`:
* `python/x86_64` (если у вас процессор Apple Silicon или ARM Linux).
* `python/aarch64` (если у вас процессор Intel/AMD).
